# 📂 Arrange Download Folder Category Wise

A simple and lightweight **Windows Batch Script** that automatically organizes your Downloads folder into category-based folders.

No installation, no external software, and no programming knowledge required. Just run the `.bat` file and your Downloads folder will be organized automatically.

## ✨ Features

- 📁 Automatically organizes files by category
- 🎬 Videos → `Videos`
- 🖼️ Images → `Photos`
- 📄 Documents → `Documents`
- 📝 Text files → `Txt Files`
- 🎵 Music → `Music`
- 🗜️ Archives → `Zip`
- 💻 Applications → `Apps`
- 📦 Unknown file types → `Others`
- 🚫 Ignores the script itself
- 🚫 Skips incomplete downloads
- ⚡ Lightweight and fast
- 🔒 Works completely locally

## 📂 Supported File Types

| Category | Extensions |
|----------|------------|
| 🎬 Videos | `.mp4`, `.mkv`, `.avi`, `.mov`, `.wmv`, `.flv`, `.webm`, `.3gp` |
| 🖼️ Photos | `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.webp`, `.heic`, `.svg` |
| 📄 Documents | `.pdf`, `.doc`, `.docx`, `.xls`, `.xlsx`, `.csv`, `.ppt`, `.pptx` |
| 📝 Txt Files | `.txt` |
| 🎵 Music | `.mp3`, `.wav`, `.aac`, `.flac`, `.m4a`, `.ogg` |
| 🗜️ Zip | `.zip`, `.rar`, `.7z`, `.tar`, `.gz` |
| 💻 Apps | `.exe`, `.msi`, `.apk` |
| 📦 Others | Unsupported file types |

## 🚀 How to Use

1. Download the `.bat` file from this repository.
2. Copy the `.bat` file into your **Downloads** folder.
3. Double-click the `.bat` file.
4. The script will automatically create the required folders.
5. Your files will be organized by category.
